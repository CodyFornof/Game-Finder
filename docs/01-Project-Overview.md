Why did I build this?
GameFinder was initially a project to display and improve my React Native/Mobile App Developer skills. It is currently still early in the process but there are plans to soon publish it to the app store when additional features and updates are added. Problem: I wanted one app that tells me where every sporting event is being broadcast. 

Solution:
React Native frontend
Node backend
Sports APIs
Firebase (if added later)

Main Features:
Splash screen displayed until the API data variable is loaded and all of the data is ready to be shown on the app
Only leagues with games on today will be displayed in the leagues bar.
Both API and web scraped data is combined to get us the game scores and updated mixed with the broadcast and where to watch each game
